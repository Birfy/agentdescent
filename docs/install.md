    <section class="qs3-more"><details><summary>What about provider keys and cost?</summary><p>A real model-backed run needs a configured provider key. <code>agentdescent doctor</code> reports missing setup. The agent shows a plan and upper bound on calls before starting. The current-main <code>agentdescent demo</code> runs offline without a key.</p></details><details id="published-v050-installation-and-source-examples"><summary>Can I install from PyPI?</summary><p>Yes: <code>pip install agentdescent</code> installs the published stable release. The Quickstart above uses current <code>main</code> because its latest agent plugin flow is not yet in the stable v0.5.0 wheel. The stable release’s source demo is documented in the <a href="../plugin-quickstart/">full plugin guide</a>.</p></details><details id="building-the-docs"><summary>How do I build these docs?</summary><p>From a checkout: <code>pip install -e ".[docs]"</code>, then <code>mkdocs serve</code> for local preview or <code>mkdocs build --strict</code> for the site build.</p></details></section>

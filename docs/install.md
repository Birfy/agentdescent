    <section class="qs3-more"><h2>Good to know.</h2><details><summary>What about provider keys and cost?</summary><p>A model-backed run needs a configured provider key. Run <code>agentdescent doctor</code> to check your setup. Your agent shows the plan and estimated call count before starting. <code>agentdescent demo</code> runs offline without a key.</p></details><details><summary>Can I explore the algorithm ports?</summary><p>All 20 algorithm ports print their configuration with <code>--dry-run</code> and make no model call. See the <a href="../self-evolution-examples/">port catalog</a>.</p></details><details id="published-v050-installation-and-source-examples"><summary>Can I install from PyPI?</summary><p>Yes. <code>pip install agentdescent</code> installs the published stable release. The command above installs current <code>main</code> with the latest agent integrations. See the <a href="../plugin-quickstart/">plugin guide</a> for the stable release.</p></details><details id="building-the-docs"><summary>How do I build these docs?</summary><p>From a checkout: <code>pip install -e ".[docs]"</code>, then <code>mkdocs serve</code> for a local preview or <code>mkdocs build --strict</code> for a site build.</p></details></section>
